# Feature extraction compatibility

The native Rust feature API implements the original shiro-xxcc processing. The command-line executable and rawfloat stream I/O are still pending. The initial Windows GNU build required a missing dlltool.exe through optional terminal-color dependencies. The clap configuration now uses the original plain CLI presentation and retains derive/std/help/usage/error-context/suggestions; the revised native matrix is running.

FeatureOptions retains MFCC, MFBE and PLPCC; order/channel adjustment; integer or fractional hops; sample rate, minimum bandwidth and mel warp; DC, RMS/dB energy, delta and acceleration options. Centers and frame counts use original f32 multiplication/division and integer truncation. Windows are centered and zero-padded, but FFT input is unshifted, as in the C tool. Magnitude and weighted RMS use original scalar products before double square roots. Filterbank output is floored at -15. Cepstral order/DC placement and zero-padded difference kernels match the source. MFBE with include_dc retains the original extra zero column. Decibel energy on silence and its derivative nonfinite values are preserved for compatibility.

The original CLI sample-rate validation checks the wrong variable; the Rust API validates the actual rate. Blackman scalar coefficient rounding can make an endpoint slightly negative. An input impulse whose only frame contribution is at that endpoint produces negative squared RMS in C. Rust clamps negative roundoff to zero before sqrt. An independent two-frame endpoint test verifies this correction; it is separate from unchanged-C comparisons.

## Original-C reference

Pinned SHIRO commit: 203ef7b71bf382c8b5ce3f86b8116f63265e2711. Pinned ciglet commit: 895ba9b1c0eabee83d3544208bbc82420efa3206.

Stage shiro-xxcc.c as original_xxcc.c, changing only its include from external/ciglet/ciglet.h to ciglet.h. tests/xxcc_oracle.c renames its main and calls the unchanged static main_xxcc processing. Compile with gcc -O2 -DFP_TYPE=float -ffunction-sections -fdata-sections -I<staging> -I<ciglet> driver.c <ciglet>/ciglet.c <ciglet>/external/fftsg_h.c -Wl,--gc-sections -lm. Invoke with destination fixture path and a temporary rawfloat input path. The original unchecked fread warning is retained; the upstream build is not claimed warning-free. Fast-math and OpenMP are disabled. Comparisons to the original -Ofast build remain pending.

XCC1 contains uint32 record count 72, then records with uint32 kind/energy mode/flags/frame length, f32 hop, uint32 input count, input f32 samples, uint32 frame/column counts and output f32 values. Kind order is MFCC/MFBE/PLPCC. Energy is none/RMS/dB. Flags use DC, delta, acceleration bits. Cases use 321 samples, lengths 511/512, hops 80/80.5, 12 requested coefficients, 13 effective channels, 16000-Hz sample rate, 400-Hz minimum bandwidth and warp 0.85. Inputs alternate silence, a 0.75 impulse at index 120, and a seventeen-sample repeating signed ramp with step 0.0625. All multi-byte fields are little-endian.

Initial Windows MSVC x86_64 results compare 6,399 output values with maximum normalized finite difference 1.036708448346817e-5. Forty-two nonfinite energy/difference values have the same infinity sign or NaN category as C; NaN payloads are not used as a cross-platform criterion. Windows MSVC x86_64/i686 and Linux GNU x86_64/i686 have passed the initial matrix. Their maximum finite normalized differences are 1.036708448346817e-5 for 64-bit and 9.73520036245573e-6 for 32-bit. The scoped bound is 2e-5. All five current tests pass on Windows MSVC x86_64/i686, Windows GNU x86_64 and Linux GNU x86_64/i686 with this bound and the revised clap configuration. The five-target worst finite normalized difference is 1.036708448346817e-5; forty-two nonfinite output categories match on every target. Shape, parameter/finite validation, empty extraction, automatic channel adjustment, MFBE zero DC column and the endpoint RMS correction have independent checks. Formatting and Clippy with warnings denied pass. No complete real-audio/model/training acceptance is claimed.
